# NexOS 0.3 — first public prototype

**NexOS is a Linux workstation for makers**: electronics, code, science and a local AI assistant,
ready out of the box, in French and Arabic. Based on Debian 13 "trixie" with KDE Plasma 6 (Wayland).

> ⚠️ **Prototype.** Tested in virtual machines (QEMU, VirtualBox), **not yet on real hardware**.
> Try it in a VM or on a spare PC — do not install it over data you care about.

## What's inside
- **Arduino Center**: 100 curated libraries (82 compiled and verified offline), board & serial diagnostics
- **KiCad 9**, **TeX Live + TeXmaker** (French/Arabic documents), **OpenJDK 21**, LibreOffice
- **Python Center**: 8 ready environments (science, AI, vision, electronics, data, code quality…)
- **Local AI assistant** (Qwen 2.5, runs offline on the CPU, loaded only when used)
- **NexOS Store**: one store for Debian packages and Flathub (Flathub is enabled automatically the first time the PC is online)
- **Snapshots & rollback**: automatic Btrfs snapshots before/after every update, one-click revert
- **Control Center**, ufw firewall on by default, AppArmor
- Graphical installer (Calamares): UEFI, Btrfs (default) or ext4, optional disk encryption

## Download
The ISO is 2.7 GB and is split into **8 parts**. Download **all** `nexos-0.3.0-amd64.iso.part0` … `part7`
plus `SHA256SUMS.txt`, then join them:

- **Windows** (Command Prompt, in the download folder):
  `copy /b nexos-0.3.0-amd64.iso.part0+nexos-0.3.0-amd64.iso.part1+nexos-0.3.0-amd64.iso.part2+nexos-0.3.0-amd64.iso.part3+nexos-0.3.0-amd64.iso.part4+nexos-0.3.0-amd64.iso.part5+nexos-0.3.0-amd64.iso.part6+nexos-0.3.0-amd64.iso.part7 nexos-0.3.0-amd64.iso`
- **Linux / macOS**: `cat nexos-0.3.0-amd64.iso.part? > nexos-0.3.0-amd64.iso`

**Verify** before using it. The result must be
`d43f9a95f9d69f2bd5d303cee31b7c163e47f229ec3d0eb50a588dafa1da72ca` (also in `SHA256SUMS.txt`):
- Windows PowerShell: `Get-FileHash nexos-0.3.0-amd64.iso`
- Linux / macOS: `sha256sum nexos-0.3.0-amd64.iso`

## Try it
- **Virtual machine**: EFI on, **Secure Boot off**, 4 GB RAM (8 GB for the AI assistant), 2+ CPUs, 25 GB disk.
- **USB stick**: Rufus (Windows, "DD image" mode) or balenaEtcher. Disable Secure Boot in the firmware.
- Live session account: `nexos` / password `nexos`. The installer creates your own account and removes it.

## Known limitations
- Not tested on real hardware yet; no proprietary NVIDIA driver; Broadcom Wi-Fi not included
- ISO bootloader not signed (Secure Boot must be off to boot the ISO; the installed system uses Debian's signed shim)
- Android project build (Gradle) and MiKTeX could not be tested in the build environment
- Performance: in our measurements NexOS uses ~1.07 GB RAM at idle, more than minimal Ubuntu/Kubuntu builds
  — see [docs/COMPARISON.md](../COMPARISON.md) for the full, honest comparison
